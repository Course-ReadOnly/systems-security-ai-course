# Stage 13 — Offensive Security

**Time budget:** 8–10 weeks part-time / 4 weeks full-time

## Objectives

Web exploitation and binary exploitation (buffer overflows, ROP, format
strings), practiced entirely against designated legal platforms
(PortSwigger's own labs, ROP Emporium, pwn.college, TryHackMe) or
self-hosted lab VMs you control — never against systems you don't have
explicit authorization to test. This stage draws directly on Stage 5
(memory/processes), Stage 7 (assembly/calling conventions), and Stage 10
(crypto) knowledge.
