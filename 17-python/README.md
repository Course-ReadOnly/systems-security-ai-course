# Stage 17 — Python

**Time budget:** 3–4 weeks part-time / 1.5 weeks full-time

## Objectives

A scripting language for tasks C is the wrong tool for — automation,
gluing tools together, Ghidra scripting. ROADMAP.md notes this stage (and
Stage 18/Go) can be pulled earlier if you want a scripting tool
alongside the C-heavy stages; that's your call to revisit, not something
to do silently.
