# Stage 7 — Assembly

**Time budget:** 3–4 weeks part-time / 1.5 weeks full-time

## Objectives

Read and write real x86-64 (and get exposure to ARM64) assembly —
calling conventions, the stack, registers, syscalls. This is what
Stage 4's CPU-simulator concepts look like on real hardware, and it's a
hard prerequisite for Stage 11 (Reverse Engineering): you can't read a
disassembler's output if you can't read assembly.
