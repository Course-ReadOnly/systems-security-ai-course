# Stage 10 — Cryptography

**Time budget:** 4–6 weeks part-time / 2 weeks full-time

## Objectives

Applied crypto, not just theory — Cryptopals' challenge-driven format
means you'll break broken crypto yourself before you ever trust
"just use AES." That instinct (why a given construction is broken, not
just that it is) is exactly what Stage 13's crypto-adjacent exploitation
and Stage 14's detection work both lean on.
