# Stage 9 — Networking

**Time budget:** 6–8 weeks part-time / 3 weeks full-time

## Objectives

Sockets, protocols, and the tools built on top of them — from a chat
server (application-layer protocol design) to a packet sniffer
(link-layer visibility). Stage 5's HTTP server already used raw sockets;
this stage generalizes that into full TCP/IP literacy, which Stage 13
(Offensive Security) assumes you already have.
