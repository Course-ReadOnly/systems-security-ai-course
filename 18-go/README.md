# Stage 18 — Go

**Time budget:** 3–4 weeks part-time / 1.5 weeks full-time

## Objectives

A second scripting/systems-adjacent language, chosen for its
concurrency model and how common it is in real security tooling
(a huge share of modern infosec tools — Nuclei, many C2 frameworks
in the wild, cloud-security tools — are written in Go). Re-does some of
Stage 9's networking projects, this time comparing Go's `goroutines`
against the manual thread/`epoll` work from C.
